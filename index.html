intel-rclone

intel-rclone is a personal backup helper, not a public service. It is the name under which the open-source rclone command-line tool, running on its owner's own computer, signs in to the owner's own Google Drive and copies encrypted backup files there once a week. It is used by one person, the owner of this GitHub account, and nobody else can sign in to it or use it. It asks Google only for the drive.file permission, so it can see only the files it created itself. See the privacy policy.
