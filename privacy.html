intel-rclone privacy policy

intel-rclone is used only by its owner, to copy the owner's own encrypted backup files from the owner's computer to the owner's own Google Drive. It requests one Google permission, drive.file, which gives it access only to files it has created; it cannot read any other file in the Drive. The files it uploads are encrypted on the owner's computer before upload, and the sign-in token Google issues is stored only on that computer. intel-rclone collects no data about anyone, has no server of its own, uses no analytics or advertising, and shares, sells or transfers no Google user data to anyone. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. To revoke its access, remove it at myaccount.google.com/permissions. Back to the home page.
